# 从零画一张动漫脸：给 AI 的完整手册

> 读者对象：另一个只会写代码、没有手感、看不到细节的语言模型。
> 目标：读完照着做，能从空画布画到"有脸、有五官、有整套头发"的成品；人类说"不对"时，知道改哪个数。
> 本文所有数值都是 320×440 画布上的实测值。换画布按比例换算。

---

## 0. 先认清你的处境

你不是画手，你是**能把形状写成公式、但看不出"好不好看"的机器**。把画画拆成五件事：

```
① 骨架   圆、直线、圆角 —— 脸和头都是它们拼的
② 五官   眼/眉/鼻/嘴，位置全部由脸宽算出来，不靠目测
③ 元素   可参数化的最小形状（这里是"柳叶"）
④ 排布   元素之间的位置/长度/角度（能用几何算的，绝不靠估）
⑤ 图层   谁压谁（画错顺序 = 东西凭空消失）
```

工作循环永远是：

```
写函数 → 出图 → 人类判"对不对" → 改一个参数 → 再出图
```

**每次只动一个变量。** 人类说不清"哪里不对"，但能说"这版比上版好"。只动一个，才知道是哪一变起作用。

画布坐标系：**y 向下为正**；角度用 `atan2(dy, dx)`，90° = 正下方。

## 1. 环境

```
Python 3 + Pillow（PIL）+ numpy
画布：320×440（头部特写）
所有形状用"掩码"(bool 数组) 表示，最后按掩码落色
```

掩码比多边形好用的原因：求交/并/差、找边界、量宽度、判空洞，全是一行 numpy。

### 1.1 第一条硬规矩：颜色必须是三元组

```python
肤 = (0xf8f2ee)          # ← 错！括号里只有一个数，这是 int，不是元组
肤 = (0xf8, 0xf2, 0xee)  # ← 对
```

**PIL 收到 int 颜色时按 `0xBBGGRR` 解析**（不是 RGB）。所以 `(0xf8f2ee)` 会被画成 `(0xee, 0xf2, 0xf8)`——整张图偏蓝发紫，看着像外星人。
本次实测：22 处颜色全部中招，排查了一小时。

省事的写法（推荐）：

```python
def 色(v):
    return ((v >> 16) & 255, (v >> 8) & 255, v & 255)
肤 = 色(0xf8f2ee)
```

**次生坑**：加了 `色()` 之后，如果某个函数里有同名局部变量（比如 `for 掩, 色 in ...`），会把它遮住并报 `UnboundLocalError`。局部变量改名即可。

## 2. 脸型：从一个圆推出整张脸

### 2.1 常量（全部从一个圆推出来）

```
cx, cy = 160, 150      # 头圆的中心
r = 100                # 头圆半径

半  = r / sqrt(2)          ≈ 70.7    # 脸的"方框"半边
方左, 方右 = cx − 半, cx + 半
方上, 方底 = cy − 半, cy + 半
小  = 半                    ≈ 70.7    # 下巴的延伸量
底Y = 方底 + 小             ≈ 291     # 下巴尖的高度
鼓  = (r − 半) × 0.5        ≈ 14.6    # 脸颊往外鼓多少
界  = r × 0.6               = 60      # 发际线中间段的半宽
rf  = 6                     # 发际线转角的圆角半径
R大 = r × 2                 = 200     # 发际线上方那条大弧的半径
眉y = cy + 半 / 2           ≈ 185
```

**为什么是 r/√2**：内接正方形。脸是一个"内接于头圆的正方形 + 向下延伸的下巴"，所以方框边长 = r√2，半边 = r/√2。

### 2.2 脸的四段轮廓

```
上边  = 头圆的上半弧（角度 −135° ~ −45°，3° 取一点）
左边  = 一条"过两个点、矢高=鼓"的圆弧（竖弦外弧）
下巴  = 从左弧末端的切点，二次贝塞尔收到底Y
右边  = 左边整条镜像
```

### 2.3 "竖弦外弧"：给两个点和一个鼓度，求圆弧

这是画脸颊的关键工具。给定竖直方向的两点 P、Q 和矢高 s（鼓多少），求过它们的圆弧：

```python
def 竖弦外弧(P, Q, s, 外=-1, n=30):
    L = abs(Q[1] - P[1])
    R = (L*L/4 + s*s) / (2*s)        # 由弦长和矢高求半径
    mx, my = (P[0]+Q[0])/2, (P[1]+Q[1])/2
    ox = mx - 外*(R - s)              # 圆心在弦的哪一侧、离多远
    aP = atan2(P[1]-my, P[0]-ox)      # 起点角
    aQ = atan2(Q[1]-my, Q[0]-ox)      # 终点角
    # 取"经过中点"的那一段弧（处理跨 ±π 的情况）
    ...
    return [(ox + R*cos(t), my + R*sin(t)) for t in 起点角→终点角]
```

调用：`左弧 = 竖弦外弧((方左, 方上), (方左, 方底), 鼓)`
—— 从方框左上角到左下角，往外鼓 14.6 格。这就是脸颊。

### 2.4 下巴：切点 + 二次贝塞尔

```python
# 左弧末端的切线方向（用最后两点求）
dx, dy = 左弧[-1] - 左弧[-4]
单位化 → d
切点 = 左弧[-1] + d × (小/3)          # 沿切线再走一小段，收得自然
下巴 = 二次贝塞尔(切点, 切点 + d×(小×0.4), (cx, 底Y), 12 段)
```

### 2.5 合成

```python
左 = 左弧 + 下巴段
右 = [(2*cx - x, y) for (x, y) in 左[::-1]]      # 镜像
轮廓 = 左 + 右 + 上弧                             # 闭合多边形
d.polygon(轮廓, fill=肤色, outline=线色)
```

**验证**：轮廓的 y 最小值应略高于 cy−r（上弧在头顶），y 最大值 = 底Y ≈ 291。

## 3. 五官：全部由"脸宽"算，不靠目测

### 3.1 分区

```python
带上 = 眉y            # 眼睛区域的上沿
带下 = 方底           # 眼睛区域的下沿
脸宽 = 2*(半 + 鼓)     ≈ 170
```

### 3.2 尺寸公式

```python
眼宽   = 脸宽 × 0.24                          ≈ 41
眼距   = 脸宽 × 0.16                          ≈ 27（两眼之间）
眼高   = min((带下−带上)×0.85, 眼宽×0.78)      ≈ 38（被两者约束）
眼中心y = 带上 + (带下−带上)×0.5
嘴y    = 方底 + 小/2       ≈ 256
鼻y    = 方底 + 小/4       ≈ 238
```

两只眼睛的中心 x：

```python
左眼x = cx − (眼距/2 + 眼宽/2)
右眼x = cx + (眼距/2 + 眼宽/2)
```

### 3.3 画一只眼（白 → 虹膜 → 瞳孔 → 高光 → 下反光 → 睫毛）

```python
def 眼(眼心x, 外符号):
    rx, ry = 眼宽/2, 眼高/2

    ① 眼白：椭圆(眼心x±rx, 眼中心y±ry)，fill=白

    ② 虹膜：正圆（不是椭圆！）
       虹r   = ry                    # 半径 = 眼高的一半 → 直径正好等于眼高
       虹心y = 眼中心y + ry×0.10      # 略低于眼中心
       框    = (眼心x±虹r, 虹心y±虹r)
       先用 PIL 的 ellipse 把圆光栅化成 L 掩码（不要用 numpy 判圆，见下面的坑）

    ③ 虹膜内部：上深下浅，分界是一条"中间高、两边低"的弧
       dx = (x − 眼心x) / 虹r
       边 = 虹心y − 0.25×虹r×(1 − clip(dx²,0,1))
       上掩 = 圆内 ∩ (y ≤ 边)   → 虹上色（深）
       下掩 = 圆内 − 上掩        → 虹下色（浅）
       （系数 0.25 控制弧度深浅：0 = 水平直线，0.5 ≈ 明显月牙）

    ④ 瞳孔：圆心 = 虹心y（严格与虹膜同心），半径 5，瞳色（最深）

    ⑤ 高光：小椭圆，大小 ~6×4，位置在瞳孔左上、且要**离开瞳孔 2 像素**
       （贴着瞳孔会糊成一团，挪开 2 格才有"玻璃感"）

    ⑥ 下方反光：与瞳孔外切、正下方，半径 = 虹r − 5（= 瞳孔下缘到虹膜下缘的距离）
       圆心 = 虹心y + 5 + 反光r；只保留落在虹膜内的部分（超出虹膜的裁掉）
       颜色比虹下色再浅一档（实测 0xa8c8e8 → 0xc8e2f4）

    ⑦ 睫毛：沿椭圆下半圈取 15 个点，每点画一个随 t 变大的小实心椭圆
       （越大越靠眼尾）；外符号 = −1 时把 x 镜像，让睫毛只朝外眼角长
```

**必须记住的坑：光栅化要统一。**

```
虹膜如果用 numpy 判圆（(x−cx)²+(y−cy)² ≤ r²），眼白用 PIL 的 ellipse
两者对边界的取整规则不同 → 同一圆心，画出来差 1 像素（实测：右眼虹膜偏右 1 格）
正解：所有"落不落在像素上"的判定都交给同一个光栅化器 ——
     用 PIL 把圆画成 L 掩码，再拿这个掩码去切上下两半
```

**动漫脸的默认值**（320×440 实测）：

```
眼宽 41 / 眼高 30 / 眼距 27
虹膜半径 15（= 眼高/2）、圆心比眼中心低 1.5
瞳孔半径 5、与虹膜同心
高光 6×4，瞳孔左上、间距 2
下反光半径 10（= 15−5），与瞳孔外切
```

```python
眉心x = cx ± (眼距/2 + 眼宽/2)
```

## 4. 发际线

发际线不是一条弧，是**五段**：

```
① 左端：从 (cx−(半+鼓), cy+7) 斜着往上
② 左角：半径 rf=6 的 90° 圆角（在外侧，让发际线转弯）
③ 顶弧：以 (cx, 方上+2r) 为圆心、R=2r 的大弧，横跨 x ∈ [cx−界, cx+界]
④ 右角：左角的镜像
⑤ 右端：镜像
```

```python
cy大 = 方上 + 2r
顶y(x) = cy大 − sqrt((2r)**2 − (x−cx)**2)      # 顶弧上任意一点的 y
```

**关键理解**：
- 顶弧是"头发往上长的那条界线"，它是往下弯的（圆心在上面）
- `界 = 0.6r` 是这条中间段的半宽；界的两端就是"**转折点**"，后面所有发片都要用到这两个点
- 转折点坐标：`(cx−界, 顶y(cx−界))` 与 `(cx+界, 顶y(cx+界))`

## 5. 基础元素：柳叶

一个"柳叶" = 一条中心线 + 沿线宽度剖面。

### 5.1 中心线：二次 / 三次贝塞尔

```python
def 贝塞尔(A, C, B, n=500):
    """二次：起点 A、控制点 C、终点 B"""
    for k in range(n+1):
        t = k/n; u = 1-t
        pts.append((u*u*A.x + 2*u*t*C.x + t*t*B.x,
                    u*u*A.y + 2*u*t*C.y + t*t*B.y))

def 贝塞尔3(A, C1, C2, B, n=500):
    """三次：起段方向由 C1 控、末段方向由 C2 控"""
    u = 1-t
    pts.append((u**3*A.x + 3*u*u*t*C1.x + 3*u*t*t*C2.x + t**3*B.x,
                u**3*A.y + 3*u*u*t*C1.y + 3*u*t*t*C2.y + t**3*B.y))
```

**必须记住的性质**：二次在起点的切线 = `C − A`；三次在起点的切线 = `C1 − A`，在终点的切线 = `B − C2`。

所以"让发根顺着某个方向长出去"= 把 C1 放在 `A + 方向 × 长度`。
"末段要竖直"= 把 C2 放在 `B − (0, 长度×系数)`。

### 5.2 宽度剖面（决定"胖瘦和尖钝"）

```python
def 剖面(t, 最宽位置=0.40, 端正=1.0):
    if t <= 最宽位置: v = sin(clip(t/最宽位置,0,1) * pi/2)
    else:             v = cos(clip((t−最宽位置)/(1−最宽位置),0,1) * pi/2)
    return v ** 端正
```

- `端正` 越大 → 两端收得越快（根细、叶身短促，根部不会贴在颅骨上）
- `端正` 越小 → 宽的部分保持得越久（饱满，但根部容易变胖）

**反直觉的坑**：想"既饱满又尖"，**一个指数做不到**。正确做法是两个因子相乘：

```python
半 = 半宽 * (1 − t**2.2)**0.70 * (1 − t)**0.35
#           └─ 凸度因子：管中段鼓 ─┘  └─ 收尖因子：管尾端锐 ─┘
# 实测：t=0 → 40, t=0.5 → 26, t=0.75 → 20, t=0.9 → 6, t=1 → 0
```

只调一个指数：要么胖到不尖，要么尖到干瘦。

### 5.3 沿法线铺宽度 → 掩码

```python
def 柳叶掩码(W, H, A, C, B, 宽, 最宽位置=0.40, 端正=1.0, n=500):
    pts = 贝塞尔(A, C, B, n)
    左, 右 = [], []
    for i, (x, y) in enumerate(pts):
        t = i/n
        切线 = (pts[i+1] − pts[i-1])（端点用差分）
        m = hypot(切线); ux, uy = −ty/m, tx/m          # 法线
        半 = 宽 * 剖面(t, 最宽位置, 端正) / 2
        左.append((x + ux*半, y + uy*半))
        右.append((x − ux*半, y − uy*半))
    return 多边形(左 + 右[::-1]) → bool 掩码
```

## 6. 排布：能用几何算的绝不靠估

### 6.1 锚点从"容器"上取

```python
1. 发片根点必须落在发际线（§4 的折线）上 → 直接在该折线上均匀取点
2. 每个锚点的"起势方向" = 该处弧线法线（不是一律向下！）
   角度 = degrees(atan2(dy,dx)) 后 +90°，得到"朝下"的法线
```

实测（r=100，中间段 x = cx±60 均分 7 点）：

```
锚点 x:  cx−60   cx−40   cx−20    cx    cx+20   cx+40   cx+60
法线角:  72.5°   78.5°   84.3°   90°    95.7°  101.5°  107.5°
```

越靠外越斜。**这一条决定"发根有没有坐在发际线里"**：所有发片一律垂直向下，看着就像贴在颅骨上。

### 6.2 间距按"轮廓相切"算

```python
# 相邻两片刚好相切：中心距 = 两片半宽之和
位[中] = cx
for k in 1..中:
    位[中−k] = 位[中−k+1] − (宽[中−k+1] + 宽[中−k]) / 2
    位[中+k] = 位[中+k−1] + (宽[中+k−1] + 宽[中+k]) / 2
```

若总跨度必须固定（比如必须是 120 格），反解宽度：`间距 = (w_i+w_j)/2` → 7 片跨 120 时 w ≈ 20。

### 6.3 先弯再量再排（第一个大坑）

**先按标称宽度定位置、再各自弯曲 → 弯完横向占宽变小 → 出现白缝。**

正确流程：

```
① 先给每片一个弯度，做出形状
② 量它在"最宽那一行"的实际横向宽度
③ 用实测宽度定间距（相邻两片半宽之和 × 0.95）
④ 位置变了 → 弯度按新位置重算 → 回到 ② 再迭代一次
```

### 6.4 复制品做分叉：偏移必须判方向

```
偏移 dx ∈ [1, 20]（只许往内）、dy ∈ [−20, 20]（上下随意）
判据：偏移在"本体尖走向"上的投影必须 ≤ 0
      > 0 时视觉上等于"顺着本体再往前延长一段"
      —— 人类会说"看着像把本体拉长了"，不叫分叉
左右两侧用不同偏移（真人头发不对称）
```

```python
u = normalize(本体尖 − 本体上边中点)
投 = dx*u.x + dy*u.y        # 必须 <= 0
```

### 6.5 发尾的水平位置 = 发根的水平位置

这条是默认规则，不这么做就会"往外飘"：

```
发片从根点垂直落下（B.x = A.x），靠 C1/C2 两个控制点做出"S 形"：
  C1 = A + 0.34L × 该处法线方向   （根部顺着发根长出来）
  C2 = B − 0.30L × (0, 1)        （末段竖直）
```

只有两种情况下故意破坏它：
1. 侧块要往外旋（"梳到后面"的感觉）→ 末端 x 往外偏 0.10~0.15r，同时把 C2 也往外偏 35%
2. 侧发/鬓角 → 几乎竖直，末端只偏 0.02r

### 6.6 M 型刘海 = 三块，中间"一顶俩"

```
中间块：宽度 = 脸宽 × 0.55（相当于两块并起来），落点拉到眉毛高度
两侧块：宽度 = 脸宽 × 0.24，内缘与中间块的外缘【相切】
        即 根点 x 偏移 = 中间块半宽 + 侧块半宽/2
图层：两侧先画、中间最后（中间压在上面 = 根点离中线越近越靠前）
```

M 型和齐刘海只差参数：齐刘海=七片等宽等高均分；M 型=上述三块。

### 6.7 中分（M 型的近亲，2026-11-17 实测）

中分跟 M 型最关键的区别：**没有盖额头的刘海，额头是露出来的**。

```
结构：中线发缝 + 左右各两片"帘" + 两侧长发 + 后发
帘：  内层短（到颧骨）、外层长（扫到脸颊外侧）
      根点贴在中缝两侧（cx ± 0.04r、cx ± 0.10r）
      起点在中线、终点往外下方 → C1 要往外偏（0.22~0.26L），C2 略回
      宽 0.30~0.34r
两侧长发：沿脸边（cx ± 脸边）竖直落下，比帘长一截（到肩下）
发缝：一条细线，从发际线往上画 0.4r（这条线是中分的辨识点，别省）
```

**后发与头顶的宽度关系（这条是比例关键）**：

```
后发最宽 = 头顶最宽 = cx ± 1.10r
做法：后发先画成多边形 → 逐列按头顶圆裁掉上角
      （每列上边界 = max(后发自身顶, 头顶圆在该列的边界)）
否则后发的方角会翘出头顶轮廓
```

### 7.1 六层（下 → 上）

```
① 后发   ② 脸   ③ 头顶   ④ 刘海   ⑤ 垫底片   ⑥ 侧发
```

### 7.2 两个会吞掉内容的致命错

**错法一：用"整张图"粘贴。**

```

```

**错法二：用"接近纯白"当背景。**

```
正解：条件改成「纯白 且 不在脸轮廓多边形内」
```

## 8. 描边：两趟画 + 清理规则

### 8.1 两趟画

```python
第 1 趟：所有叶子只填色（从外层画到内层）
第 2 趟：所有叶子的边界线统一起描在最上层
```

如果一片一片地"填色+描边"，后画的填色会盖掉前面的描边 → 要么看着一整块，要么看着漏缝。

### 8.2 边界只在需要的地方露出来

轮廓描边是自动的（`掩码 XOR 四邻腐蚀`），但**人类要的往往是"部分有、部分没有"**。实测有效的四条清理：

```
① 零件顶部的横线整条删掉（它是"接口"，不是头发的边）
② 内侧竖线只留下面一截（上面那段应该连成一体）
③ 外缘竖线删掉最上 1/4（额角处头发是连续的，不该有线）
④ 两片叶子的交界线：靠近发根那 1/3 删掉，靠近发尾那段保留
   根部无线 = 连成一整束；尾部有线 = 看出分叉
```

判断标准一句话：**"这条线在解剖上存在吗？"** 不存在的就删，存在的才留。

### 8.3 更狠的一招：同类合并成一片，只描外轮廓

如果人类说"这整块是一体的，内部那些线都去掉"，那么：

```
前发 = 头顶 ∪ 垫底片 ∪ 刘海三块        （并集，一个掩码）
只描【并集的外轮廓】，内部一条线都不留
侧发 = 单独两片，压在前发上 → 只描【靠根那一小段】(~0.38L)，用来表示它在前面
```

实测数据：合并后前发 21474 px，比三块分别描边少了一大堆内部线。

**代价**：分束感消失（整片是一块色）。所以这是"要体积感"还是"要分束感"的取舍，**必须让人类选**，不能自己定。

### 11.1 出图前的层检查（强制）

新写一个脚本时，最容易犯的错不是算错，而是**整层忘了画**——尤其"垫底片"这种藏在别人下面的层，少了也看不出来，只有人类会说"你怎么又漏了"。

所以脚本末尾必须放一段自检：

```python
应有 = {"后发": 后发掩.any(), "头顶": 头顶掩.any(), "垫底片": 垫底掩.any(),
        "帘/刘海": len(片) >= 3, "侧发": 侧掩们, "脸": True, "五官": True}
缺 = [k for k, v in 应有.items() if not v]
print("层检查：" + ("全部齐" if not 缺 else "缺 " + "、".join(缺)))
```

配套的两条纪律：

```
① 层清单以 §7.1 为准，逐项对，不凭印象
② 每层的底边/范围都要"有依据地算"（跟某个圆求交、取某条最宽行），
   不许直接写死数字 —— 写死的数字最容易连层一起忘
```

**本次教训**：中分那张第一稿漏了垫底片，文档里明明有（§9⑤、§13.5），
原因就是我凭记忆拼层。加上层检查后同类错误会被打印出来。

### 11.2 垫底片的标准算法（2026-11-17 最终版）

最初的做法是"取刘海最宽行当底边"，结果总有地方露白。正确做法是**逐列贴住上层的下缘**：

```python
# ① 先量上层（帘/刘海）的掩码
上层 = 各片叶子掩码的并集
底表 = np.full(W, np.nan)
for x in range(W):
    列 = np.where(上层[:, x])[0]
    if len(列):
        底表[x] = 列.max()          # 这一列的上层最低点 = 切口
有效 = ~np.isnan(底表)
底表 = np.interp(np.arange(W), np.where(有效)[0], 底表[有效])   # 没有上层的列用邻近列补

# ② 宽度：一直到【侧发的竖直中线】为止（cx ± 脸边），不够宽两侧会漏
# ③ 高度：从头顶下方（cy − 0.95r）铺到该列的底表
# ④ 再与头顶圆求交（把翘出轮廓的两角切掉）
# ⑤ 不描边（它应当完全藏在上面那层下面）
```

为什么这样切：底边等于上层的下缘曲线，所以垫底片**永远藏在轮廓里**，
换任何发型都成立；而"取最宽行"只是一条水平线，凡是下缘是斜的/尖的，就会露出来。

实测数据（中分，r=92）：切口覆盖 128 列；宽度到侧发中线后 20908 px（原来只到帘 bbox 时 15498 px，两侧漏）。

## 14 附：本仓库代码的实际取值（以代码为准）

正文里给的是**范围与经验值**（方便理解为什么这么定）；仓库里那两个生成器用的是下面这一组**具体值**。
两处若有冲突，以本节和代码为准。

```
半   = r / √2                    # 内接方框的半个边长
小   = 半                        # 下巴长度（常规脸；幼态取 半×0.52）
鼓   = (r − 半) × 0.5            # 脸颊鼓度；幼态取 ×0.62
眉y  = cy + 半 / 2
眼宽 = 脸宽 × 0.24               # 脸宽 = 2×(半+鼓)
眼距 = 脸宽 × 0.16
眼高 = min( (眉到下沿的高度)×0.85 , 眼宽×0.78 )
虹膜 = 正圆，半径 = 眼高的一半（上半深、下半浅，分界线按 dy² 弯曲）
```

说明：

```
· 眼高那两个上限是"别顶到眉毛、别胖成圆"的双保险，取较小值
· 眼宽 0.24 是这一版的实际取值；0.21~0.28 都做得出，差别在"可爱/冷静"
· 所有位置最后都要 round() 再栅格化，否则会出现半像素错位（见《失败记录》第三条）
```
