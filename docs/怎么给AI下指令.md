# 怎么跟画图的 AI 说清楚

> 读者是**人**。你可能没写过代码，也没想过 AI 是怎么"看"图的。
> 这篇只讲一件事：怎么用一句话，让它改对地方，而不是改出一堆你没要的东西。

---

## 一、先说清它是什么

画这种参数化像素画的 AI，本质是**一个只会算坐标、不会判断美丑的函数**。

```
你说"好看点" → 它没有"好看"这个变量，只能瞎猜
你说"这里从 0.33 改成 0.21" → 它立刻能执行，而且可复现
```

所以不是它笨，是**形容词进不去，数字进得去**。

你要做的不是描述感受，是**把你的感受翻译成三样东西之一**：

```
① 位置（哪里）：左/右/上/下、第几片、根还是梢、靠内还是靠外
② 量（多少）：几像素、几个百分点、是上一版的 1.2 倍
③ 反面（不要什么）：别碰哪儿、别超多少、删掉哪条线
```

---

## 二、三种说法，按精度排

### 1. 直接给数（最准）

```
"眼宽从 脸宽×0.21 改成 0.24"
"刘海根点从 cx−0.33W 收到 cx−0.21W"
"描边从 2 像素改成 1 像素"
```

它执行完能告诉你"改了哪一行、改完 diff 是 3 个像素"。

### 2. 相对比较（次准，日常最常用）

```
"比上一版宽 20%"
"左边那片再往中间靠一点，靠到跟右边对称"
"这个圆比上上版小一圈，回到上上版那个大小"
```

关键：**必须指名参照物**（上一版 / 上上版 / 原图 / 右边那个）。说"大一点"它不知道从哪儿起算。

### 3. 参照物（能用，但会失真）

```
"像原图那样，三片刘海把脸三等分"
"照参考图里那条斜线的走势"
```

它能从参考图里量出结构（几片、多长、往哪弯），但量不出"手感"。所以这一档要配一句兜底：**"照这个意思做，不对我再改"**。

---

## 三、六个能直接抄的句式

```
① 改一处，其他不动
   "把[右上那条刘海的末端]从[0.66r 高]改到[眼睛上方]，别的地方不要动"

② 说不，同时说保持
   "这版的问题是[左侧有两条多余的线]；[删掉它们]，[外形和宽度都保持现在这样]"

③ 让它自己量，而不是你说
   "把这版和上一版比一下，告诉我差了多少像素、差在哪块"

④ 让它先出方案
   "这个思路我不确定，你先用三五行说打算怎么改，我点头你再动手"

⑤ 让它放大局部
   "把眼睛那块裁出来放大 5 倍发我"（缩略图看不出 1 像素的差别，这条最省钱）

⑥ 让它报账
   "刚才改了什么？只列参数和旧值→新值"
```

---

## 四、这四个说法没用（都是今天真实试出来的）

```
"自然一点"        —— 它不知道"自然"对应哪个数
"再可爱些"        —— 可能对应眼高、脸短、下巴短，改错方向就是灾难
"感觉不太对"      —— 它只能靠 diff 猜，会瞎改
"随便改改看看"    —— 你会得到十版垃圾
```

要用也行，但**必须跟一句落点**：

```
"不太自然 → 我觉得是下巴太圆，试着把下巴拉长 10%，只改这一处"
```

---

## 五、说"不要"的正确姿势

"不要"最容易被误解，因为它在 AI 那边等于"删掉/关掉某个东西"，而那个东西可能还连着别的。

```
✗ "别那么花"          → 它可能把整个图案删掉
✓ "花纹只留在下摆，上半身全白"       （给边界，不给形容词）

✗ "别动脸"            → 它不知道头发和脸共用了哪些参数
✓ "只改头发，脸的四个参数（半/鼓/小/眼位）一个都别碰，改完把参数表发我核对"
```

一句话：**"不要"必须带范围**。

---

## 六、下指令的顺序（照着填就行）

```
① 部位：哪里（左刘海 / 右眼角 / 后发下摆 / 描边）
② 参数：改哪个量（宽度 / 高度 / 位置 / 粗细 / 颜色）
③ 幅度：从 A 到 B（数字、百分比、或"回到上上版"）
④ 不动的部分：明确说"其他都别动"
⑤ 验收：怎么算成了（"和原图比差 200 像素以内" / "缝没了" / "放大 4 倍看不见接缝"）
```

示例（一句完整的话）：

> 把左右两片刘海的**根点**往中间各收 20%（从 ±0.33 脸宽到 ±0.27 脸宽），**宽度和走势不变，其他部分都别动**；改完把这两版并排图发我，我看根部那条缝有没有合上。

---

## 七、改坏了怎么退回来

```
· 每次改动前让 AI 备份文件（它一般都会，但你要提）
· 每轮只改一个变量 —— 一次改三个，出问题你不知道是哪个的锅
· 觉得"越改越远"时，直接说"退回上一版"，不要试图把错的改回来
```

---

## 八、你的三句话总结

```
1. 形容词换成数：位置 + 量 + 反面
2. 参照物要说清：比"哪一版"大/小/宽/窄
3. 一次只改一处，改完先看局部放大图，再决定下一步
```

照着这三条，你不需要懂代码，也能把它指到你要的地方。

# 附：给 AI 的一节 —— 怎么向主人要信息

> 上面是给人看的。这一节给**读文件的 AI**：
> 主人说得含糊时，你的任务不是猜，是**把他缺的那一块问出来**。

## 一、先判断缺的是哪一类

```
位置缺：不知道改哪儿        → 问"是左片还是右片？根还是梢？"
量缺：  不知道改多少        → 问"从 0.33 收到 0.27，还是更狠到 0.21？"
反面缺：不知道什么不能动    → 问"脸型能不能动？还是只改头发？"
参照缺：不知道跟谁比        → 问"跟上一版比，还是跟原图比？"
验收缺：不知道什么算成了    → 自己定一个，报给他确认（"缝合上 / diff 200 内"）
```

**只问缺的那一类**。五类都问一遍，他就不想理你了。

## 二、能自己量的，不要问人

```
"这块有多大？"           → 用量图工具量，别问
"上一版多少像素？"       → diff 一下就有
"这两版差在哪？"         → 自己比，然后说"差 312 像素，集中在下巴和左刘海"
```

问人的永远只有一类：**取舍**（要可爱还是要冷静、要分束还是要干净）。这类他自己也说不准，但只有他能定。

## 三、给选项，不要给开放题

```
✗ "你想怎么改？"
✓ "两个方向：A 把下巴拉长 10%（更像少女）；B 保持现在（更幼）。选哪个？"

✗ "宽度要多少？"
✓ "收到 0.27 还是 0.21？0.27 只挡缝，0.21 会开始重叠"
```

有数值的选项，他判断起来是零成本的。

## 四、把"我不确定"翻译成"我读成 X，对不对"

```
✗ "我不太确定您的意思"          → 他要重新说一遍，白花一轮
✓ "我读成：三片等分、不留缝。对吗？不对请指出哪半句错了"
```

这是最省时间的一句，因为它让他只需说"对"或"第二半"。

## 五、三个可以直接说的提醒句

```
① "这条我不能只靠看，得给你量一下，稍等"
   —— 避免用"感觉"回答需要精度的问题

② "这轮我改了三处，但一次改三处出了问题不好定位。
   建议拆成三轮，先改宽度，你看过再动位置。"
   —— 一次一个变量，责任在你这边，不是等他提醒

③ "这轮改了 [参数]：[旧值]→[新值]，diff [N] 像素，
   集中在 [区域]。下一轮建议 [一件事]。"
   —— 每轮报账，他不用追问
```

## 六、不要问的

```
✗ "你觉得这样好看吗"        → 他在审美上能说的只有"好/不好"，信息量为零
✓ "这两版你更想要哪个"      → 选择比评价容易一百倍

✗ "还需要改什么"            → 他会说"感觉不对"，又回到起点
✓ "眼睛、头发、脸型，这三块哪块最不对？"   → 缩小到一块
```

## 七、什么时候该停下来问

```
· 要删东西（描边、图层、分束线）—— 他可能就是要那个"脏"
· 要改已经定稿的参数 —— 定稿是他拍的板，动之前说一声
· 要动存档/文件 —— 任何不可逆操作
· 你连着两轮改错方向 —— 停下来问"是不是我理解错了整体要什么"
```

## 八、一句总结

```
你负责把"感受"翻译成"参数"，并把缺的那一项问出来
他负责判断"这版对不对"
别让他学你的语言，也别自己猜他的感受
```
