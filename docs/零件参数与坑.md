## 零件-1 · 刘海中间簇（轮廓定稿 2026-11-16）

![轮廓](图/../素材/零件1-轮廓-放大.png)

**来源**：他手绘的两张图（梭形 + 复制下半块）+ 口述步骤

### 参数（画布 240×240，中心 cx=110）

```
上半梭形   y 46~114，宽 27 → 66
下半块     y 114~158，宽 66 → 44，侧边外鼓 4（顺梭形走势收，不能是直边）
中腿       y 114~158，宽 40 → 24，侧鼓 2
两个切圆   R = 150（超级大圆）
           左圆：过 (88,158) 与 (79,114)
           右圆：过 (114,158) 与 (120,114)
切法       形状 −（左圆 ∩ 右圆）    ← 是交集，不是并集
结果       左腿收成一个尖（约 x=83, y=152）；右腿底部 135~143（y=158）
           三条腿之间各留一条弧形细缝（分叉感）
```

### 制作四步

```
1. 图1 只取上半（y 46~114）
2. 图2 重做：上下边严格水平、侧边顺着梭形外鼓（66→44）
3. 两个大圆切掉"交集"：左腿尖、右腿留宽度
4. 中腿补回来（40→24），三件并起来 = 连续外轮廓 + 三条长短不同的腿
```

### 四个坑（这一片踩的）

```
① 减"并集"→ 整块被吃光；必须减"交集"
② 用两条边界分别插值拼多边形 → 边界交叉，出叶子／獠牙；要逐行算左右边界
③ 图2 用左右两条弧拼、收口没对齐 → 顶边斜 + 台阶；改成逐行画、上下边水平
④ 圆心放到形状外侧 → 切掉两边留中间；圆心要放在"想保住部分的反面"
```

## 零件-4~10：M 字刘海（七根柳叶，2026-11-17 定稿）

**跟零件-1 不是一套做法**：零件-1 是"整块的形状"，这套是"七根柳叶排布"。

### 元素：柳叶

```
参数只有四个：两个端点、弯度、最宽、最宽位置（+可选收束指数）
弯度正负 = 凹面朝哪边；收束指数越小，宽的部分保持得越久（越饱满）
工具：柳叶工具.py（可 import：柳叶掩码(W,H,A,B,弯,宽,位,端正)）
```

### 排布规则（他一条条纠出来的）

```
① 根点固定在发际线中间段上（两端正好是那两个"转折点"）
② 起势方向沿发根线的法线（越靠外越斜：72.5°→107.5°，90°=正下）
③ 发尾水平位置 = 发根水平位置（垂直落下，不往外飘）
④ 曲线是三次贝塞尔：起段 0.34 沿法线、末段 0.30 竖直 → 根部顺、尾巴直
⑤ 间距按"轮廓相切"：相邻中心距 = 两片半宽之和（不强求 1/3 线相接）
⑥ 宽度 17/18/19/19/19/18/17，总跨 110 格（发际线 120，两端各留 5）
⑦ 发尾高度统一 186，最外两根压低到 190
⑧ 图层：根点离中线越远越先画（被压）；中爪最后画，所以最前
⑨ 画法两趟：先全部填色，再统一描边（这样分束线不会被上层填色盖掉）
```

### 踩过的坑

```
① 先排后排再弯：弯了以后横向占宽变窄 → 出缝。要"先弯、量实测宽度、再定间距"
② 用"1/3 线相接"当约束 → 宽度被迫撑到 30，根部变胖像贴颅骨。放弃它，改轮廓相切
③ 后画的叶子把前面的描边盖掉 → 看着不是漏缝就是整块。改两趟画
④ 七根等长等角度 = 梳齿/帘子。真实头发要长短差 + 交叉
```

## 整体发型：六层叠法（2026-11-17 定稿）

**顺序从下往上**（先画的被盖）：

```
① 后发    大矩形，宽度 = 头顶发块宽（x cx±(r+12)），上边逐列跟着头顶圆的边界走，垂到 y≈380
② 脸      贴零件1c 生成的脸（含五官、发根线）
③ 头顶    圆（半径 r+12、中心上移 4）∩ {发根线以上}
④ 垫底片  矩形：x 100~219（=刘海最宽那行 120 格），y 73 ~（最宽行 162 上收 16 = 146）
⑤ 刘海    七根柳叶（见上一节）
⑥ 侧发    矩形+双柳叶（左右各一套，见下）
```

### 侧发参数

```
矩形：x 60~100（内边=转折点，外边=头最宽处），y 转折点 88.5 ~ 鼻子 238
本体叶：从矩形下边（宽 40）收到尖 (113.3, 291)（往内 1/3 矩形宽）
复制叶：只复制下面那片叶子，图层在本体下
        尖 = 本体尖 + 偏移（往内 1~20，上下 ±20）
        偏移在本体走向上的投影必须 ≤ 0（>0 = 看着像把本体拉长）
        左右用不同偏移
上边裁剪：上边(x) = max(转折点高度, 头顶外圆边界高度)，切掉突出的两坨
```

### 两个坑（都会让东西"凭空消失"）

```
① 用整脸图 paste 到别的图层上 → 把下层全盖掉（脸图是不透明白底）
   解法：把头发抽成"发色/描边色掩码"，只往掩码里落色
② 用"接近纯白"当背景 → 眼白也是纯白，被当成背景涂掉
   解法：条件改成「纯白 且 不在脸轮廓多边形内」
```

### 后发发尾：三个大柳叶（v17 最终定稿）

```
后发本体的平底截到 y=340，下面接三片大柳叶
三个中心：cx−69.5 / cx / cx+69.5；半宽 40；尖到 y=422
宽度剖面：半 = 40 × (1−t^2.2)^0.70 × (1−t)^0.35
   实测宽度：t=0 40 / 0.5 26 / 0.75 20 / 0.9 6 / 1 0
```

**一句话经验**："饱满但尖"靠两个因子相乘，不是一个指数能同时做到的：
凸度因子 `(1−t^2.2)^0.70` 管中段鼓，收尖因子 `(1−t)^0.35` 管尾端锐。
只调一个指数，要么胖到不尖，要么尖到干瘦。
